# Panel (use when the user asks for panel / professional depth)

Write one shared brief first: the text, the user's decisions so far, your
own line-by-line reading, your draft, and open questions. Then run five
readers in parallel, each writing a full report to a file and returning a
10-line summary. Every reader counts syllables for every line it proposes
and writes "old → new, why" for every change.

1. **Structure** — section order, where the listener understands the
   thesis, chorus options (max 2, full text), verse balance, bridge place.
2. **Language and syllables** — verify counts, split points, suffixes,
   vowel collisions, idiom, address forms.
3. **Meaning and tradition** — check the reading against the tradition the
   register belongs to (name it in the brief: e.g. Yunus Emre / Hacı Bayram
   for tasavvuf; blues; chanson), unintended comic or self-pitying readings.
4. **Music and form** — tempo, metre, mode/makam, voice, dynamic curve,
   which lines will rush or sag, section tags.
5. **Adversarial critic** — no praise; what every decision costs,
   including the user's own lines and edits. Ends with Reject / Accept /
   Ask-the-user lists.

Then decide yourself (written decisions file, numbered), run one rewriter
bound by those decisions with an "objections" section, and do your own
self-review on its output. Report your judgement, not the vote count.
